Provably Fair System

NovaLux implements an advanced provably fair system that ensures game integrity while enabling AI features.

Key Components

  • Client and Server Seed Combination: Standard cryptographic approach
  • Transparent RNG: Verifiable random number generation
  • Outcome Verification: Tools for players to confirm fairness
  • Immutable Record: Blockchain-based ledger of game outcomes
  • AI Boundary Enforcement: Clear separation of AI from outcome determination

Verification Process

  1. Player receives or selects client seed before gameplay
  2. Server generates and commits to server seed (hash provided)
  3. Game outcomes determined by combining seeds
  4. After gameplay, server seed revealed for verification
  5. Player can verify all outcomes using provided tools

AI Integration Safeguards

  • AI systems receive game state information only after outcomes are determined
  • All AI visualizations and features are clearly labeled as non-deterministic
  • Regular third-party audits verify separation of concerns
  • Detailed documentation of all AI interactions with game systems
