NovaLux AI Casino - Microservices Architecture

Introduction

The NovaLux AI Casino platform is built on a robust microservices architecture that enables scalability, resilience, and rapid feature development. This document details the individual microservices that make up the platform, their responsibilities, and how they interact to create the complete NovaLux experience.

Architecture Overview

NovaLux employs a cloud-native microservices architecture deployed on Kubernetes. Services communicate primarily through asynchronous event streaming via Kafka/Pulsar, with synchronous REST APIs for direct interactions. This approach allows for independent scaling, deployment, and resilience of each component.

Key Architectural Principles

  • Service Autonomy: Each service owns its data and business logic
  • Event-Driven Communication: Services publish events that others can subscribe to
  • Polyglot Persistence: Each service uses the most appropriate database technology
  • API Gateway Pattern: Centralized entry point for client applications
  • Circuit Breaker Pattern: Prevents cascading failures across services
  • CQRS: Separation of command and query responsibilities where appropriate
